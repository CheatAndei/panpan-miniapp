# 番番记录全局 UI 深度升级计划

更新：2026-07-27  
状态：已确认“小学高年级—初中清爽校园文具风”；阶段 1 已完成，阶段 2 首页与海报批改批次已完成

## 目标与验收

- 目标：把现有“功能已齐、页面各自生长”的界面，升级为统一、可信、角色清晰的微信小程序体验。
- 范围：40 个页面、共享组件、设计 tokens、图标、页内动效、状态与可访问性。
- 保留：Vue 3 + uni-app、业务规则、API、路由、数据、角色；森林绿不再作为主界面主色。
- 不处理：后端、数据库、部署、支付、账号体系；未确认前不改历史回看等业务流程。
- 总体验收：
  - 320、390、430px 等效宽度无横向溢出、遮挡、截断；安全区正确。
  - 加载、空、错误、禁用、成功与重试状态完整。
  - 主要操作触控高度至少 112rpx，次级操作至少 88rpx；图标按钮有可访问名称。
  - 非必要动效支持 reduced-motion。
  - `npm test`、`npm run build:mp`、`npm run check:mp` 全部通过。
  - 微信开发者工具逐批保留改前/改后截图并完成真机抽查。

## 设计方向

- 产品气质：清爽校园文具；明亮、可信、有学习动力，不做幼儿园式卡通。
- 统一底座：天空蓝 + 薄荷绿 + 阳光黄 + 纸张白；主界面取消大面积深绿。
- 教师端：效率工作台；高频任务前置、信息紧凑、待办明确。
- 家长端：成长陪伴；孩子状态、今日任务与反馈形成连续阅读。
- 学习与挑战：在统一底座上增加受控活力，不把游戏视觉扩散到管理页。
- 教育辨识：练习册页签、纸张分隔线、书本/铅笔/尺规/公式图标、进度贴纸；不用大量 Emoji。

## 阶段 1：设计底座与双场景试点

### 修改

- 扩展现有 tokens：排版、间距、表面、语义、层级、动效时长和 easing。
- 将现有森林绿主色迁移为教育蓝；正确/完成状态使用薄荷绿，奖励使用阳光黄。
- 补齐 `--page-bg`，逐步替换重复魔法值，不做一次性全仓重写。
- 扩展 `pp-icon`：名称白名单、尺寸、语义标签、装饰声明、统一图标容器。
- 升级 `pp-state`：加载/空/错状态层级、重试动作、reduced-motion。
- 试点页：
  1. `teacher-tools`：无 API、低风险，建立教师工作台样板。
  2. `learning-center`：建立家长/学习场景样板。

### 风险

- `pp-state` 覆盖 36 个页面；保持 props/events 不变，并抽查全部状态。
- 本地 SVG 不能自然继承文字颜色；首期用统一线性 SVG + 语义容器，不引入图标库。

### 验证

- 两个试点页完成 320/390/430px 截图。
- 六个教师工具入口、学段切换、今日/学习/成长导航及练习入口保持可达。

## 动效清单

- 全局按压：120ms。
- Tab / 筛选：160ms。
- 弹层：180ms 遮罩 + 240ms 上滑。
- 异步卡片：180ms 淡入上移；列表仅首屏最多 3 项错峰。
- 批改台：照片切换、旋转、学生切换 180ms。
- 保存成功：200–240ms + 可选一次轻触震动。
- 结果庆祝：1.2–1.8s，一次完成、可跳过、支持减少动态效果。

## 回归范围

- 未登录、未绑定家长、已绑定家长、多孩子、教师、多角色切换、维护模式。
- 首页、教师工具、学习中心、我的、绑定、签到、反馈、批改台。
- 36 个 `pp-state` 使用页的 loading / empty / error 抽查。
- TabBar、长姓名、长文案、零数据、弱网、权限拒绝、保存失败与重试。

## 已确认

- 目标年龄气质采用“小学高年级—初中清爽校园文具风”，避免幼儿园卡通感。
- 阶段 1 完成：全局浅色 tokens、本地图标与状态组件升级、`teacher-tools` 和 `learning-center` 双场景试点。
- 阶段 2 已允许拆分教师/家长首页视图并重排教师信息层级；认证、API、页面生命周期和轮询继续由首页控制器负责。

- 其余海报只统一浅色工作台与状态体验，继续保留反馈、竞技、宣传和通用成就各自的视觉主题及隐私边界。
