# 番番记录 UI 画像

更新：2026-08-01
状态：全项目 Candy 教辅视觉与家长欢迎转场已完成代码、测试、构建和真实页面截图验收；本任务未改海报 Canvas、未部署后端、未上传微信体验版

## 产品与用户

- 产品：教师与家长双角色的微信小程序。
- 教师核心任务：看今日待办、签到、发反馈、批改打卡、管理学习小组与教学工具。
- 家长核心任务：看孩子今日状态、学习任务、反馈、成长记录与练习结果。
- 学习场景：日常练习强调清晰与低压力；挑战、排行榜、成就海报允许更强的节奏与奖励感。

## 技术画像

- Vue 3 + uni-app + Vite，目标端为 `mp-weixin`。
- 共 43 个注册页面，当前无分包；底栏仅“首页 / 我的”。
- 全局样式与 tokens 位于 `App.vue`。
- 共享 UI：`pp-icon`、`pp-state`、`pp-avatar`、`pp-question-reader` 等。
- 图标：26 枚本地 SVG、4 枚 TabBar PNG；不依赖图标库。
- 动效：`pp-icon` 提供 `pop/ring/shine/breathe/bob` 五类语义动效，页面另有短促进入、弹层、按压与进度反馈，统一支持 reduced-motion。

## 现有设计基因

- 主色：天空蓝 `#99DEF4`、糖果粉 `#F79BC0`、便签黄 `#FFF48A`。
- 文字锚点：近黑 `#050505`；交互链接使用可读行动青 `#0B789A`。
- 表面：纸白为主，大块低饱和糖果色负责分区，不用密集描边争抢层级。
- 形态：平面教辅版式、中等圆角、低阴影、移动端大触控区。
- 品牌气质：清楚、有趣、认真但不紧张，像一本年轻的数学教辅。

### 必须保留

- “番番记录”品牌名；蓝、粉、黄三色 Candy 教辅系统与近黑大字作为主界面识别。
- 教师效率、家长安心、学生学习三个场景的差异。
- 现有业务规则、API、路由、角色、数据与存储逻辑。
- 本地图标与轻量依赖策略。
- 反馈卡、宣传海报、打卡海报、口算战绩保留各自信息结构与现有 Canvas 配色；本轮只改页面壳层，不迁移生成海报。

### 应避免

- 全站套同一种卡片，抹平角色差异。
- 紫色渐变、玻璃拟态、霓虹、巨大圆角、持续漂浮。
- GSAP、Lottie 或新大型 UI/动效依赖。
- 依赖动画理解状态；自动音效、频繁震动、长时间粒子动画。
- 多种高饱和色等面积争抢层级，或让大面积深色成为主界面底色。

## 审计结论

- 43 个注册页面、共享组件、本地 SVG 与 TabBar PNG 均收敛到天空蓝、糖果粉、便签黄、纸白与近黑体系；所有生成海报 Canvas 保持原样。
- 家长首页围绕孩子、今日任务、课后任务、成长和家校服务连续阅读；所有家长相邻功能页同步为 Candy 教辅体系。
- 教师首页将快捷工作置顶并扩为 6 项，新增“学习记录”；教师运营页保持高扫描密度，批改台支持最近 3 份、修改、预览和保存。
- 学生挑战、排行、成长与结果页使用图标、进度、徽章、错峰入场和一次性反馈获得活力，主界面保持清楚的黑字与单一视觉焦点。
- 批改海报使用绿色侧脊、薄荷数据卡与白纸构图并移除隐私说明，三组文案池各 100 条且洗牌周期内不重复；口算与压轴海报保留各自旧主题。

### 已完成：全局留白根因修复

- `App.vue` 对页面原语统一 `box-sizing: border-box`，原生 `button` 使用稳定的 flex 垂直居中并清除默认纵向 padding。
- 批改台翻页、缩放、旋转、答案卡和学生导航不再叠加“固定高度 + 上下 padding”；无照片状态压缩，有照片时才保留稳定画布。
- `pp-state` 已移除固定 `236rpx` 容器高度，短加载、空态和错误态按真实内容自然收高。
- 学习中心“今日 / 学习 / 成长”导航从 `112rpx` 收敛到 `76rpx`，并加入日历、书本和成长图标。

### 已完成：图标与动效语言

- `pp-icon` 已支持装饰/语义无障碍属性、错峰延迟以及 `pop/ring/shine/breathe/bob` 五类 transform/opacity 动效。
- 家长、教师、学生和公共功能页均有本地图标锚点；动画只绑定当前任务、提醒、完成、奖励和目标，循环卡片保持静止。
- 所有非必要动效支持 `prefers-reduced-motion: reduce`，不新增 GSAP、Lottie 或大型 UI 依赖。

## 推荐方向

`Candy 数学教辅 × 教师高效率 × 家长安心 × 学习区轻活力`

- 统一底座：纸白、天空蓝、糖果粉、便签黄与近黑；每屏只保留一个主焦点，粉黄主要用于提醒和奖励。
- 教师端：高信息密度、任务优先、明确待办和批量操作。
- 家长端：更温暖、可读、围绕孩子今日与成长叙事。
- 学习挑战：用进度、图标、一次性结果动效和少量珊瑚提醒强化奖励感，不用四色拼贴。
- 教育辨识：通过练习册页签、纸张分隔线、书本/铅笔/尺规/公式图标建立，不靠堆放卡通人物或 Emoji。

### Candy 教辅色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面底色 | `#F7FCFE` | 极浅天空纸面 |
| 纸张白 | `#FFFFFF` | 卡片、表单、弹层 |
| 天空蓝 | `#99DEF4` | 品牌、大片分区、图标容器 |
| 糖果粉 | `#F79BC0` | 欢迎、提醒、老师消息、奖励点睛 |
| 便签黄 | `#FFF48A` | 排名、数学提示、阶段重点 |
| 近黑 | `#050505` | 标题、正文、主行动按钮 |
| 行动青 | `#0B789A` | 链接、选中、需要高对比的蓝色文字 |
| 次级文字 | `#50545B` | 说明文字 |
| 分隔线 | `#DCE9ED` | 克制边框与纸张分隔 |

主界面不让蓝、粉、黄同时等面积争抢层级；近黑承担阅读和主行动，糖果色只负责结构与情绪。生成海报继续使用各自独立主题。

## 动效能力边界

- 可用：CSS/WXSS `transform + opacity`、`uni.createAnimation`、`swiper` / `movable-view`。
- 不用：GSAP、Lottie、Vue `<Transition>`、自定义小程序跨页转场。
- 节奏：
  - 按压与选中：120–180ms。
  - Tab、筛选、进度：160–220ms。
  - 弹层：遮罩 180ms，内容 220–260ms。
  - 成功反馈：180–240ms，可选一次轻触震动。
  - 庆祝：单次 1.2–1.8s，可跳过；循环装饰严格限量。
- 所有非必要动效支持减少动态效果。

## 家长欢迎转场

- 新家长最低展示 1.5 秒：“初次见面 / 正在准备你的学习记录”。
- 老家长最低展示 0.6 秒；100 条本地欢迎文案洗牌轮换，跨轮避免紧邻重复。
- 冷启动、分享入口和离开 30 分钟后的回访触发；普通站内返回不重复打断。
- 数据与欢迎动画并行；数据失败也先完成转场，再显示真实错误。
- 分享入口只接受 `home / guest / bind` 白名单目标与白名单参数，避免任意路由注入。
- 动效统一支持 `prefers-reduced-motion`，退出使用上移淡出并衔接页面淡入。
