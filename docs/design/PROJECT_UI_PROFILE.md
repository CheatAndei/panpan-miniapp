# 番番记录 UI 画像

更新：2026-07-27  
状态：已审计；已确认“小学高年级—初中清爽校园文具风”；阶段 1 与阶段 2 首页/海报批次已完成

## 产品与用户

- 产品：教师与家长双角色的微信小程序。
- 教师核心任务：看今日待办、签到、发反馈、批改打卡、管理学习小组与教学工具。
- 家长核心任务：看孩子今日状态、学习任务、反馈、成长记录与练习结果。
- 学习场景：日常练习强调清晰与低压力；挑战、排行榜、成就海报允许更强的节奏与奖励感。

## 技术画像

- Vue 3 + uni-app + Vite，目标端为 `mp-weixin`。
- 共 40 个页面，当前无分包；底栏仅“首页 / 我的”。
- 全局样式与 tokens 位于 `App.vue`。
- 共享 UI：`pp-icon`、`pp-state`、`pp-avatar`、`pp-question-reader` 等。
- 图标：20 枚本地 SVG、4 枚 TabBar PNG；不依赖图标库。
- 动效：已有 CSS/WXSS transition、keyframes、弹层进入、骨架屏、按压反馈及部分 reduced-motion。

## 现有设计基因

- 主色：森林绿、青绿。
- 表面：纸白、浅灰绿。
- 语义色：低饱和赭色警告、柔和红色错误。
- 形态：中等圆角、轻边框、克制阴影、移动端大触控区。
- 品牌气质：可靠、平静、熟人老师、家校沟通。

### 必须保留

- “番番记录”品牌名；原森林绿不再作为主界面识别色。
- 教师效率、家长安心、学生学习三个场景的差异。
- 现有业务规则、API、路由、角色、数据与存储逻辑。
- 本地图标与轻量依赖策略。
- 反馈卡、宣传海报、口算战绩等已有独立视觉主题。

### 应避免

- 全站套同一种卡片，抹平角色差异。
- 紫色渐变、玻璃拟态、霓虹、巨大圆角、持续漂浮。
- GSAP、Lottie 或新大型 UI/动效依赖。
- 依赖动画理解状态；自动音效、频繁震动、长时间粒子动画。
- 未确认前重写首页或改变业务流程。

## 审计结论

### 已改善：信息架构与首页过载

- `pages/index/index.vue` 已从约 1240 行收敛为 548 行控制器；教师、家长、欢迎和作业提醒拆为独立视图组件。
- 教师首页已按总览、优先待办、快捷工作、班级历史、练习工具与海报重排，首屏重点明确。
- 家长首页围绕孩子、今日任务、作业、状态、课表和反馈形成连续阅读；后台刷新不会再吞掉孩子切换。
- 40 个页面仅有 2 个底栏入口，深层功能依赖卡片入口和返回栈。

### P1：设计系统未收口

- 已有完整颜色、圆角、阴影、按钮和弹层基础。
- 页面与组件仍有约 1800 处十六进制色值；11 个页面完全未使用 tokens。
- 7 个页面引用未定义的 `--page-bg`。
- 6 个核心页面存在两段 `scoped style`，首页在第 916、1084 行形成两层覆盖。

### P1：组件与语义覆盖不足

- `pp-state` 已用于 36/40 页，适合成为首个稳定的状态原语。
- `pp-icon` 只覆盖约 13/40 页；其 SVG 颜色硬编码，缺少语义标签与装饰图标声明。
- 部分核心入口使用可点击 `view/text`，按钮语义、可访问名称和触控规则不统一。
- 反馈仍大量直接调用 `uni.showToast`，视觉与震动反馈未形成统一策略。

### P2：动效语言分散

- 全局已有 120–240ms 级按压、弹层与加载动画基础。
- reduced-motion 只覆盖少数页面；`mental-arena/result` 的多组循环动画风险最高。
- 签到、请假页左滑操作缺少统一的纵向方向锁。

## 推荐方向

`清爽校园文具 × 教师高效率 × 家长安心 × 学习区轻活力`

- 统一底座：天空蓝、薄荷绿、阳光黄、纸张白；大面积保持浅色。
- 教师端：高信息密度、任务优先、明确待办和批量操作。
- 家长端：更温暖、可读、围绕孩子今日与成长叙事。
- 学习挑战：用阳光黄、珊瑚橙强化奖励感，但限制持续动画。
- 教育辨识：通过练习册页签、纸张分隔线、书本/铅笔/尺规/公式图标建立，不靠堆放卡通人物或 Emoji。

## 动效能力边界

- 可用：CSS/WXSS `transform + opacity`、`uni.createAnimation`、`swiper` / `movable-view`。
- 不用：GSAP、Lottie、Vue `<Transition>`、自定义小程序跨页转场。
- 节奏：
  - 按压与选中：120–180ms。
  - Tab、筛选、进度：160–220ms。
  - 弹层：遮罩 180ms，内容 220–260ms。
  - 成功反馈：180–240ms，可选一次轻触震动。
  - 庆祝：单次 1.2–1.8s，可跳过；循环装饰严格限量。
- 所有非必要动效支持减少动态效果。
